# 阅读器

## Responsibilities

阅读器按运行形态提供两种主体：桌面为单页大图 + 滚轮翻页，手机为竖向连续滚动。两种形态都提供本章进度条与快速跳转、自动续章、上一章/下一章与章节目录；从发现入口进入时会话支持上一本/下一本漫画切换与读完自动续书。阅读位置按"每本漫画一条（章节 + 页码）"记录，离开时保存。

## Public Contract

- 桌面主体：单页大图居中显示，滚轮向下进下一页、向上回上一页；页首向上/页尾向下触发章节切换。
- 手机主体：竖向连续滚动，进度条随滚动位置更新。
- 本章进度条显示"第 N / M 页"，可拖动在章内跳转。
- 章节末尾自动进入下一章；最后一章停在章末。
- 目录：桌面为侧边面板，手机为底部抽屉；目录可切换章节。
- 工具栏三个按钮常驻：目录永远可点（章节列表为空时提示并重试）；上一章/下一章无对应章节时禁用并置灰。
- 从发现入口进入时，工具栏追加"上一本/下一本"漫画切换按钮；读完最后一章自动切到序列下一本漫画的第 1 章。从其他入口进入时无这两个按钮，最后一章停在章末。

## Invariants

- 阅读位置记录保持"每本漫画一条（章节 + 页码）"，离开阅读器时更新为最新位置；自动续章后同样更新。
- 发现会话内切换漫画前保存当前漫画的阅读进度；切换后从目标漫画第 1 章开始。
- 从首页"最近阅读"卡片或详情页"继续阅读"进入时，定位到记录的章节与页码；初始定位采用多帧重试直至目标可到达，定位过程中不触发自动续章。

## Notes

- 页码 0 起始，界面显示为"第 N+1 页"。
- 图片宽高由接口返回；未知尺寸时按 4:3 估算显示高度。
- 移动端连续滚动列表按图片宽高以固定高度渲染每一项，滚动偏移与布局一致，初始定位可精确到页；图片加载不改变布局。
- 阅读器会预加载当前页前后 1–2 张图片（全局图片缓存），翻页/滚动切换不闪屏。
