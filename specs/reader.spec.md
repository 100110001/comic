# 阅读器

## 职责

提供沉浸阅读、章内进度与跳转、章节目录、自动阅读及可选超分。桌面支持单页、双页和连续阅读；手机固定适应宽度的上下连续阅读。位置按漫画记录章节与原图页码，先保存本机，再补传服务器。

## 公开契约

- 桌面正文不常驻工具栏或进度条。右键直接打开统一阅读设置面板，顶部显示当前章节、本章页码、进度条和页码输入框；页码必须是本章有效整数，非法输入提示范围且不改变位置。面板提供目录、上一章／下一章与返回；Windows 提供全屏切换，进入全屏隐藏自绘标题栏，退出阅读器恢复非全屏。
- 桌面 `Esc` 在菜单、目录、设置或页码输入获得焦点时仍直接退出阅读器并返回进入前的页面；先写入本机断点，失败保留页面并提示重试。重复退出不会重复补传同一位置。
- 手机双击正文显示／隐藏控制层，包含返回、章节标题、菜单和关闭按钮；菜单按钮直接打开统一阅读设置面板。控制层不自动隐藏，关闭或显示均不改变正文尺寸与阅读位置。单击不翻页，不提供左右翻页或手动缩放；上下滑动可停在任意位置。
- 菜单、设置与目录均提供内部关闭按钮；关闭只收起面板，不退出阅读器。手机系统返回优先关闭面板，没有面板时返回上一页。浮层覆盖正文，不挤压或重新排列漫画。
- 阅读设置：桌面右侧面板，手机底部面板；标题和关闭固定、内容滚动。顶部统一展示当前章节、本章进度（拖动与输入跳页）及原快捷操作，下接全部展开的阅读配置、超分、自动滚动／翻页和图片信息；不再设置二级阅读设置入口。图片信息展示真实文件名、原图尺寸及当前页，未知尺寸明确标注未知。
- 桌面阅读模式提供跟随设备（单页）、单页、双页及连续阅读；宽度不足 720px 使用手机形态连续阅读但保留桌面偏好。双页按当前原图页码显示当前及后一页，方向只改变左右排列与方向操作，奇数尾页留空槽。
- 桌面分页图片按原比例居中；适应窗口显示完整页，适应宽度长图可纵向滚动，实际大小按源图像素显示并允许平移。滚轮先滚动图内内容，到边界再翻页。不提供缩放滑杆、捏合缩放或双击放大。
- 桌面连续阅读列最大宽度 960px，图片无间距衔接；滚轮滚动、页码随位置变化，滚动到底续章，短章可继续向下滚轮续章。手机后续章节按需追加到同一列表，上一章尾页不提前消失，可向上回滚已加载章节。
- 手机跨入新章节后，章节名、页码、进度范围、超分窗口和断点同步到实际阅读章节；章内跳转保留已加载章节。预取下一章不改变当前断点；下一章失败保留已有正文并在末尾提供重试，重试重新请求；空章不覆盖有效断点。
- 目录显示章节总数与当前章节，可滚动选择章节。目录首次获取失败后可重新请求；恢复目录时，已加载图片与断点继续属于实际原章节，不按列表默认索引归到首章。
- 桌面键盘：左右键遵循翻页方向，空格下一页，Home/End 到本章首／末页；连续模式定位相应图片。PageUp/PageDown 切到上一／下一章第一页，无对应章节不操作，PageDown 不触发续书。面板打开时不处理正文翻页快捷键，避免页码输入误触。
- 自动阅读为本次会话操作：连续阅读可选每秒 10—200 像素，分页可选 2—30 秒间隔。点击开始收起面板和控制层，正文提供停止入口；打开面板、双击控制层、手动拖动正文、跳页、应用后台或退出时停止。等待章节时不推进虚假位置；加载失败暂停。
- 单张图片失败点击重试；整章失败或空章显示明确提示与重试。章节错误不无限自动重试，显式重试重新请求数据。
- 普通入口最后一章停在末尾；手机末尾显示“已读完”与返回。发现会话菜单保留上一本／下一本；桌面越过末页或手机继续向下越过末尾可续书，换书先保存当前漫画断点。

## 不变量

- 本机待同步位置按服务器地址与漫画 ID 隔离，每本漫画至多一条最新断点；有效翻页、滚动和章节加载后的实际位置先写入本地。翻页不持续上传服务器。
- 离开阅读器、切换漫画和进入后台时先保存本机位置再补传；应用启动、恢复前台与切回服务器时重试待同步项。返回页面后补传仍可继续。
- 空章、章节加载失败与初始跳转的中间滚动位置不覆盖断点；过期章节请求和定位回调不得影响新章节。
- 阅读设置面板在当前漫画存在本机待同步项时显示同步入口，可手动重试。本地写入失败明确提示并允许重试，不把未落盘位置发布为已保存。
- 发现会话内切换漫画前保存当前漫画的阅读进度；切换后从目标漫画第 1 章开始。后续换书及离开时，保存的漫画、章节与页码始终属于当时正在阅读的内容。
- 从首页"最近阅读"卡片或详情页"继续阅读"进入时，定位到记录的章节与页码；初始定位采用多帧重试直至目标可到达，定位过程中不触发自动续章，也不记录临时经过的页码。

## 说明

- 页码 0 起始，界面显示为"第 N+1 页"。
- 图片宽高由接口返回；未知尺寸时按 4:3 估算显示高度。
- 章节图片 URL 带有由文件大小与修改时间组成的版本参数；同名图片替换并重新导入后，下一次获取章节数据会使用新 URL，绕过 HTTP 与 Flutter 的旧图片缓存。
- 章节图片 URL 固定绑定返回该章节数据的服务器地址；切换服务器后重新获取章节数据，不复用或动态改写旧服务器的图片 URL。
- 重新导入同名图片会使数据库中的旧宽高失效；下一次读取章节图片时按当前文件重新计算并保存尺寸。
- 连续滚动列表按实际阅读列宽度与图片宽高以固定高度渲染每一项，滚动偏移与布局一致；图片加载不改变布局。目标图片页顶超出内容的可滚动范围时定位至内容底部并保留目标页码。
- 阅读器预加载当前页及前一、后两页到全局图片缓存；尺寸确定后的首次布局和尺寸档位变化时更新预加载，翻页/滚动复用相同缓存。
- 分页图片按实际每页槽位和设备像素比解码，双页按每张图的显示区域计算；适应窗口采用 contain，适应宽度采用 fitWidth，实际大小使用原图。连续阅读按实际列宽解码，长条漫画不按视口高度缩小。尺寸策略见 `specs/image-loading.convention.md`。
- 相邻页预加载与显示使用同一尺寸缓存键；图片主体布局确定前不预加载原图，过期章节或窗口回调不继续预加载。
- 单图重试等待实际图片 provider 的缓存驱逐后重建，包含尺寸包装键，避免仅清理源 URL 而复用旧尺寸失败态。
- 阅读模式与适配切换、窗口宽高调整、桌面/手机形态切换时保持当前页；连续模式按实际列宽重新定位。恢复定位和进度跳转不触发自动续章，中间滚动页码不覆盖本机断点；定位完成后保存目标页。
- 键盘翻页仅作用于桌面形态；手机固定上下连续阅读。旧自动隐藏偏好保留兼容读取，不再影响控制层。
- 阅读器画布可选择跟随主题、深色、灰色或护眼米色，工具栏继续跟随应用主题。默认画布沿用深色黑底、浅色浅底；交互与断点不随外观变化。

- 原生断点使用应用支持目录的文件，写入完成后才可恢复；应用被强制结束时不保证收到生命周期通知。Web 使用浏览器本地存储，清理存储会移除本机待同步项。

## 可选超分

- 阅读设置面板和设置页提供相同的超分开启/自适应/关闭三态全局策略，无偏好默认自适应。任一入口修改后持久保存并立即更新当前阅读器，切章、换书、重进和重启均沿用同一策略。面板另提供重试当前窗口、清空后端超分缓存，并显示当前页状态或失败原因。
- 阅读设置显示超分关闭、处理中、排队、就绪或失败原因；不依赖图标颜色判断。就绪表示后端结果可用，增强图成功解码并显示后才在图片角落显示“2× 超分”标记；等待、关闭或解码失败时不显示标记。关闭设置后图片标记仍跟随增强图。
- 待同步阅读进度入口统一位于阅读设置；目录和上一章／下一章也位于同一面板。
- 每个阅读窗口的统一图片请求显式携带超分布尔选择。开启后按当前页与后续页顺序提交需要增强的页；动态前瞻两到十页（加当前页最多十一项），翻页后推进窗口并在章末截断，当前页优先，跳过的页不使后台页升格为当前页，后端复用已存在任务或缓存；不一次处理整本。后端预处理不依赖阅读视口尺寸；处理和下载期间继续显示章节元数据中的原图。增强图片成功解码后在相同区域覆盖原图；关闭立即恢复原图。
- 自适应按实际显示宽度乘设备像素比判断；分页适应窗口使用 contain 后宽度，双页按各页槽位计算；适应宽度与连续模式使用显示列宽，实际大小使用源图物理宽度。目标未超过原图宽度 115% 时保留原图并说明分辨率足够；未知源尺寸或显示尺寸时保留原图并说明。视口或 DPR 变化重新判断，即使解码缓存档位未变；该规则不保证增强观感更好。
- 开启/自适应时每五秒获取后端前瞻策略；请求失败回退后四页，关闭/退出停止刷新。面板显示当前预处理数量；窗口缩小约束新提交，已进入后端队列的任务继续运行。
- 原有前一页至后两页的原图预加载保持不变。超分预处理不等同于额外完整解码，增强图片仍使用显示区域与设备像素比计算尺寸。
- 超分不改写原图宽高、连续阅读项固定高度、页码、滚动定位或阅读断点，不触发额外进度记录。
- 引擎未配置、排队/处理失败、等待超时或增强图片下载/解码失败均保留原图；原图本身失败才进入原有图片重试流程。
- 切章、换书、关闭、退出或切换服务器使旧轮询失效；旧增强层的延迟解码错误须校验控制器代际与具体结果身份，不得误标新结果。
- 清空缓存先将全局策略持久切换为关闭，再清空后端缓存并回原图，两处配置保持一致。失败有提示，可重新开启或重试。
