# 阅读器

## 职责

阅读器按运行形态提供两种主体：桌面为单页大图 + 滚轮/键盘翻页，带沉浸式工具栏；手机为竖向连续滚动。两种形态都提供本章进度条与快速跳转、自动续章、上一章/下一章与章节目录，图片失败均有可恢复的重试入口；从发现入口进入时会话支持上一本/下一本漫画切换与读完自动续书。阅读位置按"每本漫画一条（章节 + 页码）"记录，有效位置变化时先保存本机断点，离开或后台时补传服务器。

## 公开契约

- 桌面主体：单页大图居中显示，滚轮向下进下一页、向上回上一页；页首向上/页尾向下触发章节切换。
- 桌面键盘翻页：←/PageUp 上一页，→/PageDown/空格下一页，Home/End 直达本章第一页/最后一页；越界行为与滚轮一致（页首回上一章、页尾自动续章/续书）。
- 桌面工具栏沉浸：无操作 3 秒后 AppBar 与进度条淡出，点击阅读区域或任意按键恢复；滚轮翻页视为阅读动作，不恢复工具栏也不重置隐藏计时；指针停留在工具栏区域时保持显示。隐藏只改变可见性，不改变布局与阅读进度；移动端不隐藏。
- 手机主体：竖向连续滚动，进度条随滚动位置更新。
- 本章进度条显示"第 N / M 页"，可拖动在章内跳转。
- 章节末尾自动进入下一章；最后一章停在章末。
- 目录：桌面为侧边面板，手机为底部抽屉；目录可切换章节。
- 工具栏三个按钮常驻：目录永远可点（章节列表为空时提示并重试）；上一章/下一章无对应章节时禁用并置灰。
- 图片失败可恢复：单张图片失败显示"点击重试"，点击后重载该图；整章加载失败或为空时，桌面与移动端均显示明确提示与"重试"入口，重试仍失败时提示保持可见。
- 从发现入口进入时，工具栏追加"上一本/下一本"漫画切换按钮；读完最后一章自动切到序列下一本漫画的第 1 章。从其他入口进入时无这两个按钮，最后一章停在章末。

## 不变量

- 本机待同步位置按服务器地址与漫画 ID 隔离，每本漫画至多一条最新断点；有效翻页、滚动和章节加载后的实际位置先写入本地。翻页不持续上传服务器。
- 离开阅读器、切换漫画和进入后台时先保存本机位置再补传；应用启动、恢复前台与切回服务器时重试待同步项。返回页面后补传仍可继续。
- 空章、章节加载失败与初始跳转的中间滚动位置不覆盖断点；过期章节请求和定位回调不得影响新章节。
- 阅读器工具栏在当前漫画存在本机待同步项时显示同步入口，可手动重试。本地写入失败明确提示并允许重试，不把未落盘位置发布为已保存。
- 发现会话内切换漫画前保存当前漫画的阅读进度；切换后从目标漫画第 1 章开始。后续换书及离开时，保存的漫画、章节与页码始终属于当时正在阅读的内容。
- 从首页"最近阅读"卡片或详情页"继续阅读"进入时，定位到记录的章节与页码；初始定位采用多帧重试直至目标可到达，定位过程中不触发自动续章，也不记录临时经过的页码。

## 说明

- 页码 0 起始，界面显示为"第 N+1 页"。
- 图片宽高由接口返回；未知尺寸时按 4:3 估算显示高度。
- 章节图片 URL 带有由文件大小与修改时间组成的版本参数；同名图片替换并重新导入后，下一次获取章节数据会使用新 URL，绕过 HTTP 与 Flutter 的旧图片缓存。
- 章节图片 URL 固定绑定返回该章节数据的服务器地址；切换服务器后重新获取章节数据，不复用或动态改写旧服务器的图片 URL。
- 重新导入同名图片会使数据库中的旧宽高失效；下一次读取章节图片时按当前文件重新计算并保存尺寸。
- 移动端连续滚动列表按图片宽高以固定高度渲染每一项，滚动偏移与布局一致，初始定位可精确到页；图片加载不改变布局。
- 阅读器会预加载当前页前后 1–2 张图片（全局图片缓存），翻页/滚动切换不闪屏。
- 单图重试前先清理该 URL 的全局图片缓存，避免旧失败态被直接复用。
- 键盘翻页与沉浸工具栏仅作用于桌面形态，移动端滚动阅读行为不受影响。
- 阅读器画布与工具栏跟随主题：深色为黑底、浅色为浅底浅工具栏；键盘/沉浸/重试/续章等交互不随外观变化。

- 原生断点使用应用支持目录的文件，写入完成后才可恢复；应用被强制结束时不保证收到生命周期通知。Web 使用浏览器本地存储，清理存储会移除本机待同步项。
