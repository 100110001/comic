# 后台页面

## 职责

- 后端静态首页 `/` 提供 API 调试，`/super-resolution-monitor.html` 提供超分请求监视；两页共享导航和深色工作台样式。
- 页面只依赖后端提供的本地资源，无外部字体、脚本或前端构建步骤。
- 超分服务与图片对比的公开契约以 `specs/super-resolution.spec.md` 为准。

## API 调试

- 常用接口目录提供健康检查、漫画列表、随机漫画、漫画详情、章节图片、超分监视状态和删除漫画示例，支持按名称、路径或方法搜索。
- 默认请求地址属于当前后端；允许编辑完整 URL 或相对地址，方法选择明确展示 GET 或 DELETE。
- 选择接口只填入请求配置，发送由用户显式触发；删除发送前须确认，取消不发起请求。
- 请求期间禁止重复发送和修改请求配置；超过 30 秒终止等待，失败或超时后恢复操作。
- 响应展示 HTTP 状态、包含响应体读取的耗时和原始内容字节数；JSON 格式化，其他内容以文本展示，响应不作为 HTML 执行。
- 可复制非空响应；复制不可用时提示手动选中复制。搜索无结果、空响应、连接失败与超时均有中文反馈。

## 监视工作台

- 请求采用紧凑六列表格：序号、文件与图片 ID、状态、处理类型、耗时、请求时间。文件与图片 ID 同行；表格宽度跟随列表区域伸缩；序号、状态、处理类型、耗时和时间列保持紧凑，文件列吸收剩余宽度，长文件名省略并提供完整名称提示。表格保留最小可读宽度，容器较窄时局部横向滚动。
- 点击请求行或键盘激活文件按钮选择预览；选中状态清晰可见，轮询更新保留仍存在的选中按钮焦点。
- 默认列表与预览按 60:40 分配可用宽度；左右分隔条支持拖动、方向键微调和 Home/End 边界调整。窗口缩放保持用户调整后的比例，列表和预览均保留最小可用宽度，刷新不重置调整结果。
- 适应窗口模式同时约束图片宽度与高度；容器变化自动重算。按原图像素缩放允许在预览内部滚动。
- 手动刷新期间显示忙碌状态并禁止重复刷新；刷新等待至多 10 秒，失败保留已有数据并明确提示可能过时。重新启用自动刷新立即获取状态。

## 不变量

- 桌面布局分别容纳列表和预览；窄屏使用上下布局，隐藏左右分隔条，表格允许在自身区域横向滚动。
- 页面控件提供中文名称、可见键盘焦点和选中反馈，两个页面可直接互相导航。
- 监视页保持只读，不启动推理或清理缓存；监视数据和文件名以文本输出。
