# 后台页面

## 职责

- 后端静态首页 `/` 提供运行总览，`/requests.html` 提供请求与缓存，`/super-resolution-monitor.html` 提供超分请求监视，`/api-debug.html` 提供 API 调试；四页共享深色工作台样式与当前页导航，桌面侧栏、窄屏顶部导航。
- 页面只依赖后端提供的本地资源，无外部字体、脚本或前端构建步骤。
- 超分服务与图片对比的公开契约以 `specs/super-resolution.spec.md` 为准。

## 总览与请求缓存

- 总览展示漫画、章节、图片数量与超分已发布缓存容量，分开展示后台连通、数据库可用、Redis连接和超分配置状态。超分配置启用不等于引擎可用，Redis连接状态不保证每次缓存操作成功。
- 普通接口、原图与超分HTTP分别展示当前进程的请求量、失败数、平均响应耗时及已知响应体大小；HTTP与超分提交是独立维度，不将它们相加。HTTP按路由分类，统一图片解析属于普通接口；超分提交统计覆盖所有来源。
- 请求与缓存页支持全部请求、普通接口、图片请求、超分请求分类，以及路径或方法搜索、响应状态筛选；普通接口额外支持命中、未命中、不可用与未使用缓存筛选。
- 普通接口缓存命中率仅以缓存查询成功的命中与未命中为分母，不可用和未使用不参与。原图展示304协商缓存次数，浏览器本地命中无法由后端观测。超分缓存命中、共享任务、新推理分别展示，命中率以保留明细中已知处理类型的请求为分母。
- HTTP趋势基于保留明细展示最近15分钟每分钟请求量及平均响应耗时；超分另展示已结束请求的总耗时趋势，包含排队、缓存命中和共享任务，不作为纯推理耗时。较早时间桶可能不完整，无数据时显示空状态。
- 从总览指标进入对应类别或异常筛选；超分异常链接定位仍保留的对应请求，失败和缓存命中按钮可筛选并选择图片。轮询更新保留仍存在的指标或异常链接焦点。
- 总览和请求页每5秒自动刷新，可暂停和手动刷新；恢复自动刷新立即读取。刷新互斥、等待最多10秒，失败保留旧值并标明过时，初次失败显示未获取数据而不是零。页面展示最后更新时间、进程起始时间与保留上限，后台基础信息每15秒更新。
- HTTP与超分提交各保留最多500条明细，累计统计限本进程，重启清空；完整采集与快照契约见 `specs/backend-observability.spec.md`。

## API 调试

- 常用接口目录提供健康检查、漫画列表、随机漫画、漫画详情、章节图片、超分监视状态和删除漫画示例，支持按名称、路径或方法搜索。
- 默认请求地址属于当前后端；允许编辑完整 URL 或相对地址，方法选择明确展示 GET 或 DELETE。
- 选择接口只填入请求配置，发送由用户显式触发；删除发送前须确认，取消不发起请求。
- 请求期间禁止重复发送和修改请求配置；超过 30 秒终止等待，失败或超时后恢复操作。
- 响应展示 HTTP 状态、包含响应体读取的耗时和原始内容字节数；JSON 格式化，其他内容以文本展示，响应不作为 HTML 执行。
- 可复制非空响应；复制不可用时提示手动选中复制。搜索无结果、空响应、连接失败与超时均有中文反馈。

## 监视工作台

- 请求采用紧凑六列表格：序号、文件与图片 ID、状态、处理类型、耗时、请求时间。文件与图片 ID 同行；表格宽度跟随列表区域伸缩；序号、状态、处理类型、耗时和时间列保持紧凑，文件列吸收剩余宽度，长文件名省略并提供完整名称提示。表格保留最小可读宽度，容器较窄时局部横向滚动。
- 点击请求行或键盘激活文件按钮选择预览；选中状态清晰可见，轮询更新保留仍存在的选中按钮焦点。
- 默认列表与预览按 60:40 分配可用宽度；左右分隔条支持拖动、方向键微调和 Home/End 边界调整。窗口缩放保持用户调整后的比例，列表和预览均保留最小可用宽度，刷新不重置调整结果。
- 适应窗口模式同时约束图片宽度与高度；容器变化自动重算。按原图像素缩放允许在预览内部滚动。
- 手动刷新期间显示忙碌状态并禁止重复刷新；刷新等待至多 10 秒，失败保留已有数据并明确提示可能过时。重新启用自动刷新立即获取状态。

## 不变量

- 桌面布局分别容纳列表和预览；窄屏使用上下布局，隐藏左右分隔条，表格允许在自身区域横向滚动。
- 页面控件提供中文名称、可见键盘焦点和选中反馈，四个页面可直接互相导航。
- 监视页保持只读，不启动推理或清理缓存；监视数据和文件名以文本输出。
