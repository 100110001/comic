# 实施计划

## 目标与技术决策

保留逐张尺寸探测，减少数据库往返；字段一致时不发送更新。

- 保留漫画数据库标题匹配及作者比较，避免改变数据库排序规则语义。
- 每漫画集中读取已有章节与图片字段，不将整库图片常驻内存；重复章节输入重新查询对应图片以保持原顺序覆盖语义。
- 新增图片连同尺寸批量插入，变化图片按主键批量更新，每批最多 200 条。使用参数化查询，不制造动态预编译缓存。
- 章节仅在排序变化时更新；新章节使用返回 ID，不推算自增 ID。
- 不增加事务或并发导入承诺；数据库失败停止并关闭连接，已成功批次保留，重跑可续接。
