# 实现计划

## 范围与方案

使用 Flutter URL 启动插件将固定的 GitHub 最新发布页交给外部浏览器。独立按钮不受应用内更新状态影响；失败使用页面提示，不覆盖更新状态。用户要求整个变更循环在同一分支完成，以一个目标为 master 的 PR 交付。

## 实现单元

### U1. 已完成：增加浏览器入口（PR #86）

- 依赖：无。
- 文件：app/lib/config.dart、app/lib/screens/settings_screen.dart、app/pubspec.yaml、app/pubspec.lock 以及插件生成注册文件。
- 实现：集中配置发布页地址；关于区使用可换行按钮组，异步打开失败后仅在页面存在时提示。
- 验证：执行仓库要求的五项检查；审查入口在检查失败和下载中仍可用、窄屏换行、失败可重试及离页安全。
- 不新增仅镜像按钮实现的单元测试；浏览器唤起需设备验证。

## 规范影响

- specs/settings.spec.md：关于区新增始终可用的 GitHub 最新发布页入口及失败反馈。
