# UI 细节打磨（标题栏合并 / 导航反馈 / 页面过渡 / 背景色差）

## Summary

按用户反馈打磨桌面 UI：应用名与顶部窗口按钮合并到同一行标题栏；侧栏导航点击/悬停增加平滑反馈；侧栏页面切换增加过渡效果；左右区域拉开背景色差；设置页文案理顺。

## Problem Frame

用户反馈：标题与窗口按钮分离、"漫画库"独占侧栏一行；导航点击缺少效果、hover 僵硬；页面切换无过渡；左右页面背景没有色差；设置页两个设置不易理解。

## Key Decisions

- **标题栏一体化**：`漫画库` 放进自绘标题栏左侧（可拖拽区域），侧栏不再放标题。
- **导航反馈**：hover 用 160ms 过渡底色，点击用更强的 ink 水波。
- **页面过渡**：切换侧栏页面用 220ms 淡入 + 轻微上移，保留 IndexedStack 状态。
- **背景色差**：新增 `navBg` 令牌（深色 `#1c2128`、浅色 `#f6f8fa`），标题栏与侧栏同色，内容区用页面背景（浅色改纯白），左右对比清晰。

## Requirements

- R1. 标题栏一行容纳"漫画库"与最小化/最大化/关闭按钮。
- R2. 侧栏导航项 hover 平滑、点击有明显反馈。
- R3. 侧栏页面切换有淡入过渡，不丢失页面状态。
- R4. 标题栏/侧栏与内容区背景有明显色差（深色与浅色都成立）。
- R5. 不改变布局结构、交互逻辑、接口与数据层。

## Acceptance Examples

- AE1. 顶部一行：左侧"漫画库"（可拖拽），右侧三按钮。Covers R1。
- AE2. 悬停导航项底色平滑过渡，点击有水波。Covers R2。
- AE3. 切换侧栏页有淡入效果，切回后首页滚动位置保留。Covers R3。
- AE4. 深色/浅色下侧栏与内容区背景可明显区分。Covers R4。

## Scope Boundaries

**Deferred for later**
