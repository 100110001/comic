# 实施记录

- 后端已返回 created_at；排序不依赖客户端日期解析。
- 原首页分页包含请求代际及动态页大小续接，复用而不新建平行分页状态机。
- 用户明确将独立发现合并至首页网格，并要求阅读时直接切下一本。
- 本仓库用户约定覆盖上游技能的多 PR/多分支流程，在同一分支完成定义、计划、实现及收割。

## 审查与验证

- 本地研究发现首页动态页大小与后端普通列表上限不同：统一首页有效页大小不超过 100，阅读序列按消费位置续接。
- 流程审查发现原换书回调异常会锁住按钮，且先推进游标会在详情失败时跳书：新会话由当前漫画 ID 定位相邻项，换书采用异常恢复与 finally 解锁；失败或无章节不推进当前漫画。
- 服务器身份同时检查代际与 ref 生命周期；首页排序、刷新不修改已创建阅读快照。
- 现有双倍字体布局测试发现新增排序文案挤占网格空间：大字体下排序入口改为带提示的图标，排序名称仍由页头和菜单提供，回归测试通过。
- 后端测试用真实 Knex 编译 SQL 并拦截执行，验证时间及 ID 排序、过滤分页与缓存身份，不访问数据库。
- 不接受整库末尾重新洗牌的旧行为；统一首页序列末尾停下，避免最近排序突然回到新入库漫画。
- 保留阅读器现有可选换书回调以兼容既有调用与测试，新首页使用有边界的阅读会话；不为此次变更重构整个阅读器。
