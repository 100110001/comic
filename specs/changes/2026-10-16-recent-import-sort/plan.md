# 实施计划

## 目标与需求

落实定义中的 R1–R5：合并浏览入口，以首页网格排序作为连续阅读顺序。沿用已有分页、主题及阅读器换书机制。

## 技术决策

- 列表增加 sort=recent，按首次创建时间及 ID 降序；random=1 优先，未指定排序保持标题排序。排序加入缓存身份。
- 首页复用现有分页状态，排序纳入查询身份；每页最多 100，兼容非随机接口限制。最近刷新保留排序，随机刷新换种子。
- 阅读会话复制已加载列表及查询参数，捕获服务器客户端；由当前漫画 ID 定位相邻漫画，详情加载失败不推进游标。按已消费位置续页，过滤边界重叠；服务器更换后拒绝旧会话续读。
- 删除独立发现导航及选书页；保留阅读器原有回调兼容性，新增首页阅读会话。所有详情开读入口传递会话。

## 数据流程

```mermaid
flowchart LR
  A[首页排序] --> B[带排序身份的分页查询]
  B --> C[漫画网格]
  C --> D[复制列表与查询参数的阅读会话]
  D --> E[详情开读]
  E --> F[阅读器切换相邻漫画]
  F --> G[同排序续页或末尾停止]
```
