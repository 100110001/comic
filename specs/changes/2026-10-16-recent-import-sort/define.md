# 需求定义

用户希望按最近入库浏览漫画，并将首页和发现合并：使用现有多漫画网格选书，阅读时直接切换下一本。

- R1. 首页提供随机与最近入库排序，最近首次入库的漫画在前；默认保留随机。
- R2. 手机和桌面取消独立发现入口，首页仍保留搜索与续读。
- R3. 从首页网格打开详情后，所有开读入口都支持按当时列表顺序上一本、下一本，读完可接续。
- R4. 未加载的后续漫画按同一排序续页；到整个列表末尾停止，避免突然换批或回到最新一本。
- R5. 切换排序、刷新、切换服务器时旧请求不能污染当前列表；阅读序列捕获开读来源。

搜索、收藏、最近阅读入口维持原有阅读方式；搜索结果暂不增加排序。无需展示具体入库时间或修改历史数据。
