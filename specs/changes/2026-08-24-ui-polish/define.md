# 全 App UI 视觉精修

## Summary

在现有 GitHub 深色风格基础上做全 App 视觉精修：统一设计令牌（颜色/圆角/间距/字体层级）与组件主题，逐屏打磨外壳导航、首页/搜索、详情、发现、我的/列表与阅读器界面。只改视觉，不动布局、交互与数据层。

## Problem Frame

当前 UI 功能完整但视觉细节粗糙：配色与圆角在各处硬编码且不一致，默认 Material 组件（Slider、按钮、输入框）与自定深色配色打架，AppBar 纯色无层次，空态/失败态样式简陋，卡片与列表项缺少统一规范。用户明确要求"全 App 一起打磨"。

## Key Decisions

- **保留深色基调**：延续 `#0d1117`/`#161b22` 背景体系与 `#58a6ff` 强调色，不换风格、不加浅色主题。
- **以设计令牌统一**：集中定义颜色、圆角、字体层级与间距令牌，替换散落各文件的硬编码。
- **组件级主题**：AppBar、按钮、输入框、Slider、导航、Tab、SnackBar 等走 `ThemeData` 组件主题，消除默认组件与自定配色的冲突。
- **只改视觉**：布局结构、交互逻辑、接口与数据层全部不变。
- **状态页统一**：空态/失败态抽成共用组件，全 App 一致。

## Requirements

**主题与令牌**

- R1. 全局颜色/圆角/字体/间距由集中令牌定义，主色调延续现有深色体系。
- R2. 所有 Material 组件通过主题统一，不再与自定配色冲突。

**卡片与列表**

- R3. 漫画卡片（网格）统一圆角、边框/阴影、封面占位与文字层级；收藏角标样式一致。
- R4. 列表项（最近阅读/收藏/收藏作者）与详情章节列表统一缩略图圆角与文字层级。
- R5. 详情页头部信息区面板化，按钮与信息层级清晰。

**页面**

- R6. 外壳导航（桌面侧栏/手机底部 tab）视觉精修，选中态与间距统一。
- R7. 首页、发现、搜索的 AppBar、输入框、加载/空/错误态样式统一且精致。
- R8. 阅读器工具栏、进度条、目录与状态页精修，保持既有交互不变。

**约束**

- R9. 不改变任何布局结构、交互逻辑、接口与数据层行为。

## Acceptance Examples

- AE1. 桌面首页网格卡片圆角/阴影/文字统一，收藏角标在浅色与深色封面上都可读。Covers R3。
- AE2. 全 App 空态与错误态使用同一组件，图标/文案/按钮层级一致。Covers R7。
- AE3. 阅读器进度条与工具栏在新主题下协调，滚轮翻页、点击呼出等行为不变。Covers R8。
- AE4. AppBar/按钮/Slider 等默认组件不再出现与自定配色冲突的样式。Covers R2。

## Scope Boundaries

**Deferred for later**

- 浅色主题、封面图重绘、图标重绘、动画体系（页面转场）、布局结构调整（卡片列数、导航结构）。

## Dependencies / Assumptions

- 纯前端 `lib/` 改动；无接口、数据层或后端变更。
- 交互与布局行为保持现状，spec 的 Public Contract 不因本次改动变化。
