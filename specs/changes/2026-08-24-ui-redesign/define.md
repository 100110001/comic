# UI 视觉改版（现代深色风格，参考 Codex / Discord / Kook）

## Summary

把全 App 视觉从"GitHub 开发工具风"改造成更现代的深色 UI：更柔和的层次背景、更大的圆角、新的强调色、卡片细边框 + 轻阴影 + hover 态、导航圆角胶囊选中态、更精细的字体层级与间距。阅读器保持黑底沉浸，交互与数据层不变。

## Problem Frame

用户认为当前 UI 仍然不够好看，希望参考 Codex、Discord、Kook 等现代应用的美感。现有代码已完成令牌化（`AppColors` + 组件主题），改版主要落在令牌值与组件细节，风险可控。

## Key Decisions

- **方向一（推荐）：Discord 深色风**——柔和分层灰（`#1e1f22` / `#2b2d31` / `#313338`）、蓝紫强调（blurple 系 `#5865F2`）、圆角 12–16、细边框 + 轻阴影、导航圆角胶囊。
- **方向二：Codex 桌面风**——更素净的黑白灰 + 蓝色强调，更接近现有风格但更圆润、层次更细。
- **方向三：Kook 风**——更亮一点、强调色偏青绿。
- **阅读器保持黑底沉浸**，工具栏/进度条随主题微调。
- **交互与布局不变**，只改视觉令牌与组件样式。

## Requirements

- R1. 全 App 采用新的深色视觉体系：背景层次、强调色、圆角、边框、阴影统一。
- R2. 卡片、按钮、输入框、导航、Tab、开关、SnackBar 等组件按新体系精修，含 hover/选中态。
- R3. 浅色模式同步改版，与深色同源。
- R4. 阅读器保持黑底沉浸，工具栏与进度条与新体系协调。
- R5. 不改变布局结构、交互逻辑、接口与数据层行为。

## Acceptance Examples

- AE1. 首页网格卡片在新体系下观感统一，hover 有轻微抬升/高亮。Covers R1, R2。
- AE2. 桌面侧栏选中态为圆角胶囊，未选中图标清晰可辨。Covers R2。
- AE3. 浅色与深色模式切换后全 App 协调，阅读器黑底不变。Covers R3, R4。

## Scope Boundaries

**Deferred for later**

- 页面转场动画体系、图标重绘、封面重绘、自定义字体。
