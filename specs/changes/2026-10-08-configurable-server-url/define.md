# feat: 支持配置漫画服务器地址

## Summary

让用户在设置页查看、修改并测试漫画服务器地址，保存后立即让整个应用改用新地址并重新加载服务端数据；网络失败以可理解的中文信息呈现。

## Problem

客户端当前固定连接一个局域网地址。电脑 IP、运行设备或网络环境变化后，用户只能修改代码并重新构建；请求失败也无法区分地址错误、连接失败、超时和服务端错误。

## Requirements

- R1. 设置页提供服务器地址输入、测试连接和保存操作，并在桌面与手机入口中使用同一套设置。
- R2. 地址保存到本地，应用重启后继续使用；没有保存记录时沿用当前默认地址。
- R3. 地址只接受完整的 `http://` 或 `https://` URL，保存时去除多余的末尾斜杠。
- R4. 测试连接不改变当前已保存地址，并明确显示连接成功或中文失败原因。
- R5. 测试失败不阻止保存，方便在服务器暂时离线时预先配置；界面应明确提示该地址尚未验证成功。
- R6. 保存后立即切换到新服务器，并重新加载所有服务端数据，不能继续展示旧服务器的会话缓存。
- R7. 所有漫画 API 请求使用统一的 15 秒超时、HTTP 状态检查、响应格式检查和业务错误处理。
- R8. 用户能够区分地址无效、服务器不可连接、请求超时、服务端拒绝请求和响应异常。
- R9. 封面与章节图片必须随当前服务器地址生成，切换服务器后不继续请求旧服务器的资源。

## Success Criteria

- 用户无需重新构建应用即可在不同电脑或局域网地址之间切换漫画服务器。
- 测试按钮不会意外切换当前数据源；保存按钮即使在服务器离线时也可完成配置。
- 保存新地址后，首页、发现、搜索、详情、收藏、最近阅读和章节图片都从新服务器重新获取。
- API 请求不再无限等待，也不再把非成功 HTTP 响应或无效 JSON 当作正常数据解析。
- 网络相关错误以中文呈现，并保留现有重试入口。

## Key Decisions

- 服务器地址是应用级本地偏好，不与主题或窗口设置绑定，也不上传到后端。
- “测试”和“保存”是独立操作；可达性不是保存配置的前置条件。
- 保存地址属于数据源切换，所有服务端会话状态统一作废；主题、窗口和更新设置不受影响。
- 更新清单仍使用独立的公开地址，不随漫画服务器地址变化。

## Scope Boundaries

### Included

- 单个漫画服务器地址的编辑、校验、测试、保存和重启恢复。
- 漫画 API 与图片资源使用动态服务器地址。
- 统一的请求超时和中文网络错误。
- 数据源切换后的 Riverpod 服务端状态刷新。

### Deferred to Follow-Up Work

- 局域网自动发现服务器。
- 多个服务器配置、历史地址或快速切换列表。
- 自动重试、离线浏览或跨服务器数据合并。

### Outside This Change

- 登录、权限、HTTPS 证书部署和公网暴露方案。
- 后端监听地址、端口或 CORS 策略调整。
- 应用更新清单地址配置。

## Dependencies and Assumptions

- 漫画服务器继续提供健康检查接口，测试连接只验证这是可识别的本项目后端。
- 用户负责确保设备能够访问所填写的局域网或公网地址。
