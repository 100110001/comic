# 实现记录

- 服务器地址按 origin 校验；保存值损坏时启动流程回退默认地址，不阻断应用启动。
- 本地偏好先写成功再推进运行时代际，避免当前运行与重启后的数据源不一致。
- 漫画 API 的统一客户端集中处理超时、HTTP 状态、业务 envelope 和响应格式；更新服务保持独立。
- 为保持每个阶段提交都可编译，U1 新增实例客户端并暂时保留旧静态 API；U2 完成 provider 迁移后再删除旧入口。
- 测试夹具中的中文 HTTP 响应需要显式声明 UTF-8；生产响应会按服务端响应头解码。
- 服务端查询 provider 全部依赖当前 API 客户端；首页、搜索和发现的手动异步操作在写状态前检查会话代际，旧 mutation 完成后也不会失效新会话。
- 数据源切换除了依赖传播，还显式销毁所有简单查询、family 与有状态查询，避免 Riverpod 刷新态短暂保留旧服务器数据。
- 封面与章节图片在反序列化时绑定响应所属服务器；`withFavorited` 保留该地址，章节图片的 `?v=` 版本参数也保持不变。
- 设置页只能从应用根外壳进入；详情或阅读器路由覆盖外壳时无法同时修改服务器，因此不需要把旧实体 ID 映射到新服务器，也不增加强制导航逻辑。
- 设置页把“测试连接”和“保存”保持为独立动作；输入变化会使旧测试结果失效，测试失败不阻止保存离线地址。
- 现有错误页、重试按钮和操作反馈继续沿用原交互，只把底层分类后的错误转换为稳定中文提示，避免把网络失败误显示为空列表。
