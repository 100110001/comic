# 更换应用图标

## 目标与范围

使用用户分享的粉色背景少女头像作为 App 图标，保留原图构图、人物和粉色背景。覆盖 Windows 程序与托盘、Android 启动器、iOS 和 Web。仅调整图片资源及对应视觉约定，不改变业务行为。

## 验收

各平台图标来自同一张原图；普通图标保持原图比例；Android 自适应与 Web maskable 图标留出系统裁切空间；iOS 图标不含透明通道。全部操作位于从 master 创建的独立工作空间与 codex/app-icon 分支，最终 PR 由用户合并。
