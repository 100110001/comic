# 实现记录

## 设计与实现

- 用户批准设计稿后，将水印文字统一为 `DEVELOP`。
- 水印位于全局路由上方的安全区浮层，阅读器和应用弹窗均在其下方。
- 浮层忽略指针事件，应用正文布局不受影响。
- Windows 标题文字原本距左侧 16px，角标会覆盖文字；开发构建调整到 64px，正式构建保持 16px。
- 整个定义、计划、实现、收割遵循用户要求，在同一分支与同一最终 PR 中完成。

## 自审记录

- 正式构建直接返回原内容，没有水印浮层。
- 调试及性能分析构建通过 `kReleaseMode` 的同一判断显示水印并避让标题。
- 浅色及深色分别使用强调色和对应 `onPrimary`，文字行高为 1，适配窄斜角条带。
- `IgnorePointer` 保证水印不阻挡标题栏拖动、双击、页面返回或阅读操作。
- `SafeArea` 保证手机系统状态栏区域不覆盖水印；系统原生弹窗不属于应用路由范围。
- 自审未发现其他需要修改的问题。未进行原生设备截图验证。
