# 设置页与浅色/深色/跟随系统主题

## Summary

新增设置页，提供"浅色 / 深色 / 跟随系统"三种外观模式，偏好本地持久化；为浅色模式建立完整浅色令牌，全 App（含阅读器）跟随主题切换。

## Problem Frame

当前 App 只有固定的 GitHub 深色风格。用户希望像常见应用一样支持浅色模式、深色模式与跟随系统，并能在一个设置页里切换。

## Key Decisions

- **设置页先做"外观"区**：主题三选一，后续再扩展其他设置项。
- **偏好本地持久化**：用 `shared_preferences` 存主题模式，单机应用无需后端参与。
- **浅色沿用 GitHub 浅色体系**：白/浅灰底、`#0969da` 强调、深灰文字，与深色令牌一一对应。
- **主题令牌扩展为双套**：通过 `ThemeExtension` 提供浅/深两套颜色，组件从主题取色而非硬编码。
- **阅读器跟随主题**：浅色下阅读器为浅底浅工具栏，保持交互不变。
- **入口**：桌面侧栏加"设置"，手机端"我的"页右上角齿轮进入设置页。

## Requirements

**设置页**

- R1. 设置页提供"浅色 / 深色 / 跟随系统"三选一，切换即时生效。
- R2. 主题偏好持久化，重启 App 后保持上次选择。

**主题**

- R3. 深色模式维持现有外观；浅色模式为完整浅色体系，覆盖外壳、首页/搜索、详情、发现、我的/列表与阅读器。
- R4. 跟随系统时，亮/暗跟随操作系统外观。
- R5. 阅读器在浅色下为浅底浅工具栏，阅读交互（键盘/沉浸/重试/续章）不变。

**入口与约束**

- R6. 桌面侧栏与手机"我的"页均可进入设置页。
- R7. 不改变任何既有布局结构、交互逻辑、接口与数据层行为。

## Acceptance Examples

- AE1. 在设置页选"浅色"后全 App 立即变浅色；重启后仍为浅色。Covers R1, R2。
- AE2. 选"跟随系统"后，切换系统外观 App 自动亮/暗切换。Covers R4。
- AE3. 浅色模式下进入阅读器，页面为浅底浅工具栏，键盘翻页与点击呼出正常。Covers R5。

## Scope Boundaries

**Deferred for later**

- 其他设置项（阅读方向、默认字号、缓存管理等）、主题跟随的深度定制（自定义强调色）。

## Dependencies / Assumptions

- 新增依赖 `shared_preferences`（本地偏好存储）。
- 纯前端 `lib/` 改动；无接口、数据层或后端变更。
