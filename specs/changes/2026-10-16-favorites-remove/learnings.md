# 检查与实现记录

## 初次检查

- 浏览与书库：全局搜索被嵌套路由覆盖；收藏 mutation 使用离页后的 WidgetRef；成功到详情重读之间存在旧值窗口；同作者其他详情未同步；我的页滑动标签不刷新；下拉刷新提前结束且部分短列表不能触发。
- 应用壳与设置：动画 key 销毁 IndexedStack；服务器保存收尾依赖页面引用；主题和托盘忽略持久化失败；损坏类型偏好可能阻止启动；非支持平台误用 Windows 安装包；安装回调缺少离页检查。
- 阅读器：换书吞掉本机保存失败；系统返回先退页再保存；部分快捷键、滚轮与分页拖动不停止自动阅读。
- 已核查且未发现明确新缺陷：搜索历史串行保存、查询代际、API 请求合并与错误转换、作者样本匹配、复制完整文本、目录操作防重复、手机追加章节、超分自适应与轮询隔离、断点上传版本确认。

## 流程说明

用户扩大范围并要求优化逻辑，按原仓库偏好在同一分支完成定义、计划、实现与收割，最终 PR 交由用户合并。

## 实现与审查

- 收藏查询改用可更新状态，服务器确认后立即发布，再刷新；同一目标并发操作合并。搜索按页面分离，已存在查询统一同步收藏，进行中的列表读取记录并应用期间的确认，完成后释放记录。
- 审查指出直接增加原始查询层会导致现有 invalidate 继续读取缓存，放弃该方案，保持既有刷新入口有效。
- 收藏卡片增加独立取消按钮及等待状态；保持首页、搜索卡片角标仅展示。作者卡片使用页面上下文显示结果，避免最后一行销毁后成功提示丢失。
- 已确认的空收藏属于有效缓存；后台刷新失败继续展示空态，不退回骨架或整页错误。
- 下拉刷新等待真实请求，失败保留内容并反馈；短列表仍可下拉。Riverpod 默认重试会延迟失败反馈，相关查询显式关闭自动重试，使用现有手动重试入口。
- 桌面转场最初仅移除变化 key，会使后续转场消失；审查后改稳定页面栈和独立动画控制器，保持 220ms 转场及减少动画偏好。
- SharedPreferences 写入前先改内存缓存，持久化失败须重新读取持久值；主题、托盘、服务器地址均处理失败缓存回退。
- 仅将锁定版本的 shared_preferences_platform_interface 从间接依赖声明为测试直接依赖，用于真实持久化失败回归，不升级版本或增加运行时依赖。
- 阅读器系统返回改先保存；审查发现 PopScope 会阻止 iOS 原生边缘手势，补充边缘横滑到同一保存入口，非边缘和纵向操作不触发返回。
- 新阅读器测试中未等待假网络图片解码导致等待动画超时；按现有 settleReader 辅助等待图像完成。换书失败会收起菜单，重试测试先重新打开菜单，保持真实交互。
- 桌面测试手动覆盖平台在断言检查前未恢复，改用 TargetPlatformVariant。
- 新服务器加载及失败时不能采用框架保留的旧服务器 previous 值；同服务器后台刷新仍应保留内容。正在补充来源隔离回归。
