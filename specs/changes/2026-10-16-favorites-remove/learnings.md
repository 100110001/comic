# 检查与实现记录

## 初次检查

- 浏览与书库：全局搜索被嵌套路由覆盖；收藏 mutation 使用离页后的 WidgetRef；成功到详情重读之间存在旧值窗口；同作者其他详情未同步；我的页滑动标签不刷新；下拉刷新提前结束且部分短列表不能触发。
- 应用壳与设置：动画 key 销毁 IndexedStack；服务器保存收尾依赖页面引用；主题和托盘忽略持久化失败；损坏类型偏好可能阻止启动；非支持平台误用 Windows 安装包；安装回调缺少离页检查。
- 阅读器：换书吞掉本机保存失败；系统返回先退页再保存；部分快捷键、滚轮与分页拖动不停止自动阅读。
- 已核查且未发现明确新缺陷：搜索历史串行保存、查询代际、API 请求合并与错误转换、作者样本匹配、复制完整文本、目录操作防重复、手机追加章节、超分自适应与轮询隔离、断点上传版本确认。

## 流程说明

用户扩大范围并要求优化逻辑，按原仓库偏好在同一分支完成定义、计划、实现与收割，最终 PR 交由用户合并。
