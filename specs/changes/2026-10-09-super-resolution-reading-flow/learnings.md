# 实现记录

规划审查：设置偏好只读入阅读器初始化，不监听重建，防止覆盖临时关闭；autoDispose 保证重进读取新默认。原有预处理已有当前页加后两页。统一入口必须真正支持关闭请求；引擎错误不阻止原图响应。

实现与审查：
- 设置用启动加载及 overrideWith，写入成功才改变偏好；非法保存值回退关闭。阅读器 read 默认值，临时开关不持久化，切章保留、退出重进恢复。
- 关闭窗口仍实际调用统一解析并携带 false；仅超分处理及轮询停止，原图不受影响。
- 统一请求返回原图地址和可选任务或错误；处理异步，不等待 GPU 结果。ID/来源/版本严格绑定，逐图引擎异常仍返回 200 原图。
- 提交完整当前页及后两页窗口，避免只提交未完成子集时优先级错位；后端复用已有任务与缓存。后端推理预处理不依赖前端视口尺寸，原图解码预加载仍等视口。
- 共享同文件但不同图片 ID 时，提交返回与监视记录绑定各自请求 ID；轮询继续按已绑定键恢复身份。
- 合并独立监视页分支，方便本分支的阅读请求直接观察；旧任务 API 保留兼容。
- 真实 HTTP + GPU 验证关闭不启动引擎、真实推理、缓存别名、禁用和故障仍返回原图、布尔与版本校验。Flutter 格式、analyze、80 项测试；后端格式、lint、build 通过。
- 规划审查未发现重大阻塞；设置改变不覆盖阅读器临时选择，旧成功/失败仍由代际隔离。
