# 后端页面体验优化

## 目标

为后台使用者统一 API 调试首页和超分监视页的视觉与交互，方便查找接口、识别请求状态和对照图片。

## 要求

- R1. 两页提供一致的导航、颜色、间距、焦点反馈和窄屏布局。
- R2. 调试首页显示接口名称与方法，支持搜索、显式发送、响应复制和完整请求状态反馈。
- R3. 请求默认使用当前后端地址，请求中避免重复发送，失败和超时可以重新操作。
- R5. 监视请求采用紧凑表格，图片预览占用较小区域，适应窗口同时约束宽高。
- R4. 超分监视保留只读行为、两秒刷新、搜索筛选及原图对比，并改善刷新反馈与选择可见性。

## 边界

沿用静态页面与现有 API；不调整数据库、推理服务、认证或 Flutter 产品功能。保留删除漫画的既有确认步骤。

## 验收

桌面与手机均可操作；键盘可选接口和对比模式；断连、空列表、非 JSON 响应和复制失败均有中文提示。

- R6. 左右区域支持拖动调整，键盘可微调宽度；窄屏使用上下布局。
