# 实施记录

- U1：采用共享 CSS 和原生 HTML/JavaScript，保留既有静态资源服务。
- 首页提供显式方法选择与发送，超时为 30 秒，耗时覆盖响应体读取。
- 既有默认 localhost 地址不适合远程访问，改为当前 origin。
- 自查：删除入口只选择、不自动发送；发送仍有确认。响应以 textContent 输出，避免解释返回 HTML。

- 用户补充：监视页面改为六列请求表格，桌面右侧预览固定为 360px，中等屏幕 320px；压缩页头、概况和表格间距。
- 适应窗口同时约束宽高，并观察容器尺寸变化；像素缩放继续允许在预览内部滚动。
- 浏览器验收：桌面及 320/390/800/1024px 不产生页面横向溢出，六列表头、360px 预览与图片宽高边界通过。
- 浏览器验收：默认地址、JSON/文本/500、30 秒超时、忙碌互斥、复制、删除取消、搜索、空状态、模式切换、刷新失败保留数据、选中焦点均通过；使用模拟响应，无数据库访问。
- 仓库门禁：Dart 格式 0 变更，flutter analyze 无问题，flutter test 80 项通过，后端格式与 lint 通过。后端已有 CRLF 格式误报经 Prettier 规范化，无服务逻辑差异。
- 自查：用户文件名与响应均采用 textContent；静态预览路径校验保留；监视不触发推理或缓存清理；没有新增服务端契约。
