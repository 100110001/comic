# 实施方案

## 问题与范围

统一配色与组件层次，重排详情页；替换阅读器控制入口，支持手机连续跨章。后端接口与引擎保持既有契约。

## 关键决策

- 主题令牌统一覆盖首页、搜索、发现、书库、设置和公共状态组件，各页再针对留白与操作顺序调整。
- 阅读器浮层由页面内状态控制，使桌面 Esc 能直接返回阅读器上一页，手机返回优先关闭面板；浮层不挤压漫画布局。
- 手机连续列表保存已加载章节与图片映射，当前章、页码和超分始终使用当前可见章节；懒加载下一章且使用请求代际拒绝旧数据。
- 自动阅读只在正文可交互且应用前台时运行，打开菜单、手动跳转或离开时暂停。

## 实施单元

### U1. 全应用视觉与阅读交互

状态：实现与验证完成，待同一 PR 收割规范。覆盖 R1—R6。

- 文件：app/lib/theme.dart、app/lib/main.dart、app/lib/screens/、app/lib/widgets/reader_settings_controls.dart、app/lib/widgets/reader_progress_bar.dart，以及必要的设置和平台适配文件。
- 顺序：主题与详情 → 菜单与控制层 → 连续跨章与自动阅读 → 边界验证 → 规范收割。
- 验证：更新既有阅读器集成测试以覆盖新入口、返回、跨章与断点，检查窄屏及大字体。执行仓库要求的五项门禁。

## Spec Impact

- specs/ui-style.convention.md：更新配色、层次、详情排版和阅读浮层。
- specs/reader.spec.md：更新桌面菜单、手机手势、连续跨章、进度和关闭行为。
- specs/settings.spec.md：更新按设备暴露的阅读配置及自动阅读。
- specs/app-shell.spec.md：同步外壳视觉与不改变的响应式边界。

## 风险

跨章异步加载、初始断点定位和章内跳转不能将临时位置写入断点；测试需要覆盖加载失败、空章和过期请求。示意图中的虚构字段不转成空壳功能。
