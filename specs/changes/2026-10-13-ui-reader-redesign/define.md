# 已确认需求

- R1. 全部页面采用深色炭灰、浅色暖白、紫色强调，使用中性表面及留白区分区域，保留自由窗口和动态漫画网格。
- R2. 详情页上方封面与信息、下方自然高度章节目录；手机紧凑排列。收藏及打开后端目录在前，阅读进度提示之后是最后一个开始／继续阅读按钮。
- R3. 桌面默认沉浸，右键菜单内部显示当前章节、章内页码、进度条及输入页码跳转；菜单提供设置、目录、全屏和返回；所有浮层内部有关闭按钮，Esc 直接退出阅读器。
- R4. 手机只有适应宽度的上下连续阅读，自动衔接下一章。双击显示／隐藏控制层，包含返回、章内进度、菜单和关闭按钮，不自动隐藏。系统返回优先关闭菜单／面板，再退出阅读器。
- R5. 不提供手动缩放。桌面设置在右侧、手机在底部，标题和关闭固定；阅读、超分、自动滚动／翻页、图片信息全部展开。超分沿用真实固定 2× 引擎，不加入示意图中的虚构模型。
- R6. 跨章滚动后章名、页码和阅读断点跟随实际可见位置；跳转按本章计算。保留搜索、收藏、服务器隔离、本机先写入的阅读进度及超分回退行为。

用户要求讨论完一次完成，同一分支、一个目标 master 的 PR，覆盖默认技能的分阶段 PR 与重复确认流程。图中封面和示例文案仅作视觉参考。
