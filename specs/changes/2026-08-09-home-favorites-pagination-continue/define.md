# 首页收藏角标、随机种子分页与悬浮续读条

## Summary

首页与搜索页的漫画卡片显示"已收藏"角标（纯展示）；首页随机网格改为种子分页：进入/刷新生成随机种子，按种子稳定随机排序，每页条数按屏幕列数动态计算（列数 × 6），滚动加载更多，刷新换种子重排；首页底部以悬浮条取代顶部"最近阅读"卡片，点击直接续读。

---

## Problem Frame

首页随机网格目前一次拉取全库（pageSize=500），返回体大且随库增长不可扩展；收藏状态只在详情接口返回，首页/搜索卡片看不到已收藏的漫画；全量随机在刷新时会整体重排，打乱用户正在看的位置。"继续阅读"入口是首页顶部卡片，占据首屏空间且与网格割裂，续读作为高频动作更适合放在底部悬浮。

---

## Key Decisions

- **角标纯展示。** 收藏切换仍集中在详情页，卡片角标只表示状态，避免卡片点击与角标点击冲突。
- **种子分页替代全量随机。** 前端每次进入/刷新生成随机种子，后端按 `RAND(种子)` 排序并支持 offset 分页；同一会话内顺序稳定、不重复，刷新换种子重排。
- **页大小按屏幕动态计算。** 每页条数 = 当前列数 × 6（约两屏高度），手机 3 列 → 18 条，桌面 7 列 → 42 条。
- **返回详情页只同步收藏状态，不重排列表。** 已加载的列表内容和滚动位置保持不变。
- **悬浮条取代顶部卡片。** 首页顶部不再显示"最近阅读"卡片，续读入口统一为底部悬浮条。
- **悬浮条有记录即显示，无记录隐藏，不提供手动关闭。** 只在首页出现，详情页保留自己的"继续阅读"按钮。

---

## Requirements

**收藏角标**

- R1. 列表接口（`GET /api/comics`）返回每条漫画的 `favorited: boolean`。
- R2. 首页与搜索页卡片在已收藏时于封面右上角显示红心角标，未收藏不显示。
- R3. 角标为纯展示：点击角标不改变收藏状态，卡片点击仍进入详情页。
- R4. 从详情页返回首页/搜索页后，角标与最新收藏状态一致，且列表顺序与已加载内容不变。

**随机种子分页**

- R5. 首页随机网格按随机种子稳定排序分页加载，滚动接近底部时加载下一页。
- R6. 每次进入首页或下拉刷新时生成新种子，重新洗牌。
- R7. 每页条数按当前网格列数动态计算（列数 × 6），随窗口宽度变化调整。
- R8. 随机分页过程中不出现重复或遗漏的漫画。

**搜索页**

- R9. 搜索页沿用关键字分页，不受随机种子影响；搜索结果卡片同样显示收藏角标。

**悬浮续读条**

- R10. 首页存在阅读记录时，底部显示"继续阅读"悬浮条（封面缩略图、标题、"第 X 话 · 第 Y 页"）。
- R11. 悬浮条左右与底部保留间距，手机端悬浮于底部导航上方，不遮挡导航。
- R12. 无阅读记录时悬浮条不显示；不提供手动关闭。
- R13. 点击悬浮条直接进入阅读器并定位到记录的章节与页码。
- R14. 悬浮条只在首页出现，不影响详情页等其它页面。
- R15. 首页网格滚动内容不被悬浮条遮挡（网格底部预留空间）。
- R16. 首页顶部原有的"最近阅读"卡片移除，由悬浮条取代。

---

## Key Flows

- F1. 滚动加载更多
  - **Trigger:** 首页随机网格滚动接近底部。
  - **Steps:** 用当前种子请求下一页（页大小 = 列数 × 6）→ 追加到列表尾部。
  - **Covered by:** R5, R7, R8
- F2. 刷新重排
  - **Trigger:** 用户进入首页或下拉刷新。
  - **Steps:** 生成新随机种子 → 重置列表 → 加载第一页。
  - **Covered by:** R6
- F3. 详情返回同步
  - **Trigger:** 用户从详情页返回首页/搜索页。
  - **Steps:** 获取最新收藏集合 → 更新本地卡片的角标状态，不重排列表。
  - **Covered by:** R4
- F4. 悬浮条续读
  - **Trigger:** 用户点击首页底部"继续阅读"悬浮条。
  - **Steps:** 读取该漫画的记录（章节 + 页码）→ 打开对应章节 → 定位到页码。
  - **Covered by:** R10, R13

---

## Acceptance Examples

- AE1. **Covers R1, R2.** Given 某本漫画已收藏，When 用户浏览首页/搜索列表，Then 该卡片封面右上角显示红心角标；未收藏的漫画不显示。
- AE2. **Covers R4.** Given 用户从首页进入某漫画详情并取消收藏，When 返回首页，Then 该卡片角标消失，列表顺序和已加载内容不变。
- AE3. **Covers R5, R8.** Given 首页随机网格共 154 本、桌面 7 列（每页 42 条），When 用户连续滚动到底，Then 分页加载完成且 154 本全部出现、无重复。
- AE4. **Covers R6, R7.** Given 用户下拉刷新或重新进入首页，When 网格重新加载，Then 生成新的随机顺序，且每页条数按当前列数计算。
- AE5. **Covers R10, R13.** Given 用户最近读过《XXX》第 3 话第 10 页，When 打开首页，Then 底部出现《XXX》的悬浮条，点击后进入第 3 话第 10 页。
- AE6. **Covers R12.** Given 用户没有任何阅读记录，When 打开首页，Then 不显示悬浮条。
- AE7. **Covers R15.** Given 首页有阅读记录，When 用户滚动网格到底部，Then 最后一排卡片可完整看到，不被悬浮条遮挡。
- AE8. **Covers R16.** Given 用户打开首页，Then 顶部不再显示"最近阅读"卡片，续读入口为底部悬浮条。

## Scope Boundaries

Deferred for later:

- 点击角标直接切换收藏
- 收藏角标出现在"我的"列表与最近阅读卡片
- 搜索页分页策略调整（页大小动态化）
- 悬浮条样式定制（主题切换、紧凑/宽松模式）
- 悬浮条手动关闭或"稍后提醒"、多本漫画轮换展示
- 分页随机与角标之外的其他列表增强

---

## Dependencies / Assumptions

- 列表接口需新增 `seed` 查询参数支持（后端按 `RAND(seed)` 排序）；不改变现有非随机路径。
- 假设：每页行数固定为 6（约两屏），后续可按设备习惯调整。
- 收藏状态同步依赖现有 `GET /api/mine/favorites` 接口。
- 假设：随机种子在前端生成并随请求传递，同一会话内保持不变。
- 悬浮条依赖现有"每本漫画一条阅读记录（章节 + 页码）"数据与 `GET /api/mine/recent` 接口。
- 假设：悬浮条显示最近读过的一本漫画。
