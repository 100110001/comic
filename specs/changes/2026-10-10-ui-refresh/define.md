# 全应用简洁书库界面

## 概述

用户认为现有整套界面笨重，确认整体预览后要求实施。以漫画封面为视觉主角，统一轻量导航、清晰文字层级和低装饰控件。

## 需求

- R1. 首页、搜索、书库、详情、发现、设置和阅读器采用同一套浅色与深色设计。
- R2. 减少面板描边，封面文字区保持等高且不增加虚构内容。
- R3. 设置合并阅读与外观，桌面选项右置，窄屏及大字体自动换行。
- R4. 所有现有数据、阅读断点、导航、搜索、收藏、超分与更新行为保持。
- R5. 手机 320px、大字体和桌面布局不溢出。

## 边界

预览只作为视觉方向；续读仍为五秒浮条，发现仍为三卡拖拽，阅读器常驻目录、换章与超分文字状态。不修改后端业务、数据库、平台图标和依赖。
