# 设置与外观

## Responsibilities

提供设置页与应用级配置：漫画服务器地址、主题、全局阅读配置与窗口行为均可调整并持久化。入口为桌面侧栏设置与手机我的页右上角齿轮。

## Public Contract

- 设置页按“外观与窗口 / 阅读器 / 漫画服务器 / 关于”分组；漫画服务器区显示当前地址，允许编辑、测试连接和保存。
- 服务器地址只接受 `http` 或 `https` origin（主机与可选端口）；拒绝 user-info、路径、查询和 fragment，保存时移除首尾空白与尾斜杠。
- “测试连接”只验证输入中的候选地址，不改变当前数据源；输入变化会清除旧测试结果，晚到的旧结果不得覆盖当前输入的状态。
- 测试失败不阻止保存。保存不同地址后立即切换数据源并清除旧服务器内容；保存相同地址不触发刷新。
- 地址在本地偏好中持久化，并在应用首个漫画请求前恢复；无记录或保存值损坏时使用内置默认地址。本地写入失败时保持当前运行地址不变。
- 设置页“外观与窗口”区提供主题三选一（跟随系统/浅色/深色），切换即时生效。
- “阅读器”区与阅读器内面板提供相同的全局选项：阅读模式（跟随设备/单页阅读/双页阅读/连续阅读）、翻页方向（从左到右/从右到左）、页面适配（适应窗口/适应宽度/实际大小）、阅读背景（跟随主题/深色/灰色/护眼米色）、自动隐藏工具栏及超分策略（开启/自适应/关闭）。两处功能与配置值一致，布局可不同；任何一处保存成功后即时同步，应用于所有漫画。
- 新安装的阅读偏好默认为跟随设备、从左到右、适应窗口、跟随主题背景、开启自动隐藏；以版本化 `readerPreferences.v1` 本地 JSON 偏好持久化，并在首次构建前恢复。无效条目独立回退默认，整体损坏回退默认；两入口并发修改串行合并，先保存再发布，失败保留旧值并提示可重试。分页适配用于单页与双页，连续阅读保持适应宽度。
- 超分开启固定 2×，自适应按原图与显示物理像素决定是否增强，关闭使用原图。无偏好默认自适应，以 `superResolutionMode` 的 on/adaptive/off 持久化并在首次阅读前恢复；新值无效或缺失时迁移有效旧 `superResolutionDefault` 布尔值。写入串行，成功后才改变全局策略并更新当前阅读窗口，失败明确提示；两入口都可选择全部三态。
- “外观与窗口”区提供关闭窗口时最小化到系统托盘开关（仅 Windows，默认开启）：开启时关闭窗口退到托盘，关闭时直接退出。
- 设置页提供“关于”区：显示当前版本并可手动“检查更新”；有新版本时显示版本号与更新说明，可一键下载安装。Windows 走静默安装（Inno `/VERYSILENT`），Android 唤起系统安装器；失败可重试。
- 主题偏好以本地偏好存储持久化（`shared_preferences`），无记录时默认跟随系统。
- 桌面侧栏"设置"与手机"我的"页齿轮均可进入同一个设置页。

## Notes

- 设置内容居中且最大宽度 800px；宽屏说明与控件横向排列，窄屏或大字体改为纵向排列。互斥选项可换行，内容可滚动；服务器输入与按钮按可用空间排列。阅读器内使用紧凑面板，保持相同选项名称与含义。

- 浅色/深色双套颜色令牌由 `app/lib/theme.dart` 的 `AppColors`（`ThemeExtension`）提供，组件经 `context.appColors` 取色；`MaterialApp` 同时注册浅/深主题并按 `themeMode` 切换。
- 阅读器默认背景与工具栏跟随主题；用户可全局覆盖阅读画布背景，工具栏仍沿用主题。
- 版本单一事实源为 `app/pubspec.yaml`；发布用 `scripts/release.ps1` 同步 `app/installer.iss` 版本、生成 `releases/update.json`（公开 releases 仓）并打 tag；更新清单地址在 `app/lib/config.dart` 集中配置。
- 更新清单地址独立于漫画服务器地址；切换漫画服务器不会改变应用更新来源。
