# 后端请求与缓存观测

## 职责

- 为漫画后台提供当前进程的请求、缓存与库规模只读快照；观测本身不改变业务缓存、原图传输调度或超分推理行为。
- 页面与交互契约见 `specs/backend-pages.spec.md`；超分提交与任务身份以 `specs/super-resolution.spec.md` 为准。

## 公开契约

- `GET /api/admin/dashboard` 返回标准业务响应，数据包含 `timestamp`、`infrastructure`、`traffic`、`superResolution`，响应禁止缓存。
- `infrastructure` 包含 `sampledAt`、`library`、`cache`、`redis`。库数量为漫画、章节和图片记录数；可用状态为 `ready`，读取失败或超时为 `unavailable` 且数量为 `null`。
- `cache` 返回已发布超分文件的 `count`、`bytes`、配置上限 `maxBytes`；目录可读为 `ready`，不存在为 `missing` 且数量为零，不可读或探测超时为 `unavailable` 且数量为 `null`。只统计规范命名的已发布WebP，不包含临时文件。
- `redis` 为 `ready` 或 `unavailable`，仅表达已有客户端连接状态；观测不主动重连。基础信息采样合并在途请求，结果复用15秒；等待至多3秒，超时仍保留底层在途探测以免后续刷新重复占用资源。
- `traffic` 包含进程起始时间 `startedAt`、保留上限 `limit=500`、累计完成数 `total`、分类累计 `totals`、最近结束在前的 `records`。
- HTTP分类 `image` 为 `/static/` 原图，`upscale` 为 `/api/super-resolution/` 专用接口与增强文件，其余 `/api/` 为 `api`；统一图片解析 `/api/images/resolve` 属于普通接口。GET健康检查、后台快照、超分监视、策略及任务状态轮询不计入业务请求。
- 每条HTTP明细包含 `id`、`category`、`method`、`path`、`status`、`aborted`、`requestedAt`、`elapsedMs`、`bytes`、`cache`；只记录路径，不记录查询参数、正文或请求头，路径最多512字符。
- 请求在完成或断连时只记录一次；断连标记 `aborted=true`、`status=0`，与HTTP错误一起计入失败数。耗时从进入业务处理前开始，包含原图并发额度等待。
- `bytes` 是完成响应的Content-Length，不是网络实际流量；HEAD、304、204为零，缺少长度或连接中断为 `null`。累计保留已知字节与未知大小次数，不猜测缺失值。
- 普通接口缓存结果为 `hit`、`miss`、`unavailable`、`unused`，章节图片列表与下述稳定查询标记Redis读取结果；读取失败不冒充正常未命中。缓存不可用仍沿用业务查询降级。
- `totals` 为每类累计请求数、失败数、304次数、已知字节数、未知字节次数、耗时总和及四种缓存结果计数。累计不受明细淘汰影响，进程重启全部清空。
- `superResolution` 保持已有超分监视快照语义；一次HTTP解析可能提交多张图片，不能与HTTP记录一一对应或直接相加。

## 不变量

- 观测数据仅存在于内存，HTTP明细与超分提交各有独立500条上限。
- 数据库或磁盘故障不阻止其它内存统计返回；故障显示不可用，不伪造健康状态或空库。
- 磁盘统计不初始化引擎、不创建目录、不删除文件，不主动采样GPU或启动任务；容量允许短暂过时，文件扫描期间被回收不视为整体失败。
- 浏览器本地图片缓存命中不会到达后端，304只能表示协商缓存，不能冒充全部图片缓存命中率。

## 普通接口缓存

- 分页列表、搜索、固定种子随机列表、漫画详情、最近阅读、收藏漫画和收藏作者使用 Redis 缓存，有效期 60 秒；仅保存成功业务响应，单条超过 2 MB 不写入。章节图片列表保留原有 24 小时有效期。
- 缓存身份区分路由、规范化分页、关键词、排序与随机种子，最近入库、标题与随机列表不能串用缓存；无种子随机列表、随机漫画专用接口、实时监视和操作接口不使用该缓存。
- 写操作成功返回前，使受影响查询的旧缓存不可用于新请求：阅读进度影响最近阅读与本漫画详情；漫画收藏/取消影响列表、搜索、固定种子随机、收藏列表与本漫画详情；作者收藏/取消影响作者列表与漫画详情的作者收藏状态。
- 启动与导入继续通过项目代际使旧缓存整体失效；修改前已开始的查询即使晚返回，也不能把旧内容保存为新请求可用的缓存。
- Redis 读取失败回退业务查询并标记不可用；缓存失效失败不撤销已提交业务修改，该进程停止使用扩展缓存直到重启，避免恢复连接后继续读取旧状态。后台 Redis 连接状态与此旁路状态含义不同。
