# 应用外壳与首页

## Responsibilities

应用外壳按运行形态选择导航骨架：Android/iOS 恒为手机形态；Windows/Linux/macOS 与 Web 按窗口宽度在桌面与手机形态间切换。桌面形态为左侧边栏 + 内容区，手机形态为底部"首页/我的"两个 tab。首页在两种形态下一致：底部悬浮"继续阅读"条 + 种子随机分页的漫画网格。

非目标：响应式 Web 的像素级适配、窄窗口侧边栏收起行为（待后续）。

## Public Contract

- 形态判定：Android/iOS 恒为手机；其余平台窗口宽度 ≥ 720px 为桌面、否则手机；窗口跨阈值时实时切换。
- 桌面导航：左侧边栏（首页/最近阅读/收藏）+ 内容区；手机导航：底部"首页/我的"两个 tab。
- 原"发现"页已移除，随机展示并入首页。
- 首页底部悬浮"继续阅读"条：有阅读记录时显示最近读过的一本（含封面与"第 X 话 · 第 Y 页"），无记录时不显示，不提供手动关闭；点击直接进入阅读器并定位；只在首页出现。
- 首页主体为全部漫画的网格，按随机种子分页展示；下拉刷新换种子重新洗牌。
- 首页与搜索页的漫画卡片在已收藏时于封面右上角显示红心角标（纯展示）；从详情页返回后角标与最新收藏状态一致，列表顺序与已加载内容不变。
- 漫画网格列数随可用宽度分档（<600 → 3 列，依次至 ≥1600 → 7 列），超宽屏内容最大 1920px 居中；卡片高度 = 封面（3:4）+ 固定文字区，按卡片宽度动态计算。
- 搜索：桌面端首页顶栏常驻输入框；手机端首页搜索图标进入全屏搜索页。
- 桌面侧栏的"最近阅读/收藏"页与手机"我的"使用同一套列表数据与交互。

## Notes

- 手机浏览器按设备系统识别（Android/iOS 浏览器视为手机形态）。
- 形态切换发生在外壳层，页面内部不散落平台分支。
- Windows 桌面版关闭窗口时最小化到系统托盘；托盘单击恢复窗口，右键菜单提供"显示主窗口/退出"。
- Windows 桌面版鼠标侧键（后退键）触发页面返回。
