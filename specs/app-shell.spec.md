# 应用外壳与首页

## Responsibilities

应用外壳按运行形态选择导航骨架：Android/iOS 恒为手机形态；Windows/Linux/macOS 与 Web 按窗口宽度在桌面与手机形态间切换。桌面形态为左侧边栏 + 内容区，手机形态为底部"首页/我的"两个 tab。首页在两种形态下一致：顶部"最近阅读"卡片 + 全库随机网格。

非目标：响应式 Web 的像素级适配、窄窗口侧边栏收起行为（待后续）。

## Public Contract

- 形态判定：Android/iOS 恒为手机；其余平台窗口宽度 ≥ 720px 为桌面、否则手机；窗口跨阈值时实时切换。
- 桌面导航：左侧边栏（首页/最近阅读/收藏）+ 内容区；手机导航：底部"首页/我的"两个 tab。
- 原"发现"页已移除，随机展示并入首页。
- 首页顶部"最近阅读"卡片只显示最近读过的一本（含封面与"第 X 话 · 第 Y 页"），无记录时不显示；点击直接进入阅读器并定位。
- 首页主体为全部漫画的网格，默认随机顺序；下拉刷新重新随机。
- 搜索：桌面端首页顶栏常驻输入框；手机端首页搜索图标进入全屏搜索页。
- 桌面侧栏的"最近阅读/收藏"页与手机"我的"使用同一套列表数据与交互。

## Notes

- 手机浏览器按设备系统识别（Android/iOS 浏览器视为手机形态）。
- 形态切换发生在外壳层，页面内部不散落平台分支。
