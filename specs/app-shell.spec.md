# 应用外壳与首页

## 职责

应用外壳按运行形态选择导航骨架：Android/iOS 恒为手机形态；Windows/Linux/macOS 与 Web 按窗口宽度在桌面与手机形态间切换。桌面形态为左侧边栏 + 内容区，手机形态为底部"首页/我的"两个 tab。首页在两种形态下一致：底部悬浮"继续阅读"条 + 支持随机与最近入库排序的漫画网格。

非目标：响应式 Web 的像素级适配、窄窗口侧边栏收起行为（待后续）。

## 公开契约

- 原生 Windows/Android 的正式构建在业务导航与进度补传初始化前检查更新；开发构建不自动联网检查。更新门位于导航树外，强更时卸载业务路由并停止其进度生命周期补传，返回和鼠标侧键不能绕过；普通提示可稍后处理且保留路由状态。版本与断网策略见 `specs/versioning.convention.md`。

- 构建身份：`debug` 与 `profile` 在应用安全区左上角持续显示 `DEVELOP` 斜角水印，覆盖首页、其他路由、阅读器及应用内弹窗；`release` 不显示。水印不占用正文布局空间、不拦截指针事件，手机避开系统状态栏，Windows 标题文字避让水印。
- 形态判定：Android/iOS 恒为手机；其余平台窗口宽度 ≥ 720px 为桌面、否则手机；窗口跨阈值时实时切换。
- 桌面导航：左侧边栏（首页/最近阅读/收藏/收藏作者/设置）+ 内容区；手机导航：底部"首页/我的"两个 tab（"我的"内含最近阅读/收藏/收藏作者三个列表，右上角齿轮进入设置页）。
- 桌面侧栏宽216，使用蓝灰工作台主题、16号导航文字和14号分组说明；将首页归为“浏览”，最近阅读/收藏/收藏作者归为“我的书库”；个人列表页展示标题和说明。手机底部使用带蓝色选中指示的 Material 3 导航栏，默认高度80、标签14号。
- 首页网格统一选书，详情开读后可按首页顺序连续切换漫画（详见 specs/reading-sequence.spec.md）。
- 首页底部悬浮"继续阅读"条：阅读记录首次可用或最近漫画、章节、页码改变时，显示最近读过的一本（含封面与"第 X 话 · 第 Y 页"），5 秒后自动收起；同一位置的普通刷新不重复提示，无记录时不显示，不提供手动关闭；点击直接进入阅读器并定位；只在首页出现。
- 续读条居中且最大宽度为 520px；只在浮条显示期间预留列表底部空间，收起后释放留白。
- 首页主体为全部漫画的网格，支持随机推荐与最近入库排序；随机模式下拉刷新换种子，最近模式刷新最新列表。
- 首页与搜索页的漫画卡片在已收藏时于封面右上角显示红心角标（纯展示）；从详情页返回后角标与最新收藏状态一致，列表顺序与已加载内容不变。
- 漫画网格列数随可用宽度分档：<480 → 2 列，480–599 → 3 列，600–899 → 4 列，900–1199 → 5 列，1200–1599 → 6 列，≥1600 → 7 列。超宽屏内容最大 1920px 居中；卡片高度为封面（3:4）加等高文字区，按卡宽和系统字体缩放计算。
- 搜索：桌面端首页顶栏常驻输入框；手机端首页搜索图标进入全屏搜索页。两个搜索栏都有历史入口，打开受高度限制的可滚动面板，点击关键字回填并搜索；手机空搜索页直接显示历史列表。
- 首页区分“随便看看”“最近入库”与“搜索结果”并展示数量；“换一批”重新洗牌，“刷新结果”重新查询当前关键字，不清空搜索。桌面搜索框提供显式提交与清空按钮。
- 桌面侧栏的"最近阅读/收藏"页与手机"我的"使用同一套列表数据与交互。
- 同一桌面外壳内切换侧栏保持页面实例与输入、滚动等页面状态；转场动画独立运行，不通过重建页面栈实现。收藏页漫画和作者提供直接取消入口，等待、成功与失败规则见阅读记录与收藏规范。

## 说明

- 手机浏览器按设备系统识别（Android/iOS 浏览器视为手机形态）。
- 形态切换发生在外壳层，页面内部不散落平台分支。
- Windows 桌面版关闭窗口默认最小化到系统托盘，可在设置页关闭（关闭后点 X 直接退出）；托盘单击恢复窗口，右键菜单提供"显示主窗口/退出"。
- Windows 桌面版隐藏系统标题栏，由 App 自绘标题栏（顶部拖拽区 + 最小化/最大化/关闭按钮）；拖拽区悬停及拖动时使用普通箭头鼠标图标，关闭按钮遵循设置页的托盘开关。
- Windows 关闭窗口或从托盘退出前等待活跃阅读器的本机断点写入完成，网络补传不阻塞关闭；本机写入失败时保留窗口供重试。
- Windows 桌面版鼠标侧键（后退键）触发页面返回。阅读器进入全屏时隐藏自绘标题栏，离开全屏后恢复。
