# UI 样式约定

## 职责

规定 App 浅色与深色界面的视觉层次、组件样式和交互反馈。现有代码中残留的硬编码色值属于历史偏差，新代码使用主题令牌。

## 设计令牌

- 颜色由 `AppColors` 的浅/深两套 `ThemeExtension` 提供，组件通过 `context.appColors.*` 取色。
- 深色：背景 `#0d1117`、面板 `#161b22`、卡片 `#1c2128`、导航 `#21262d`、边框 `#30363d`、强分隔线 `#21262d`；强调 `#58a6ff`、主文字 `#e6edf3`、次要文字 `#8b949e`、收藏粉 `#f778ba`、星标黄 `#f5c542`。
- 浅色：背景 `#f3f5f9`、面板和卡片白色、导航 `#edf1f7`、边框 `#e0e5ed`、强分隔线 `#e8ecf2`；强调 `#0969da`、主文字 `#1f2328`、次要文字 `#57606a`。
- 页面背景、导航和内容面板保持可辨认的层次，主要阅读操作使用强调色。
- 圆角：卡片 14、缩略图 8、按钮 12、浮层 18、小角 6；集中在 `app/lib/theme.dart` 的 `kRadius*` 常量。
- 中文字体不打包：主题与 AppBar 标题声明简体中文回退栈（微软雅黑 → 苹方 → Noto Sans CJK SC → Source Han Sans SC）。

## 页面与组件

- Material 组件由 `buildAppTheme()` 统一提供样式；页面使用统一的标题、说明、间距与面板。
- 桌面导航提供品牌区和“浏览/我的书库”分组，选中项以淡强调底色和强调图标标识。手机使用 Material 3 `NavigationBar`，保留“首页/发现/我的”三个目的地。
- 首页明确显示“随便看看”或“搜索结果”、数量与对应刷新操作；桌面常驻搜索框提供提交和清空入口。
- 漫画封面保持 3:4，卡片采用主题面板、圆角与细边框。无封面时用书本图标占位；收藏角标位于右上角，话数/页数角标位于右下角，深色遮罩上的文字使用白色以保持对比度。
- 漫画标题最多两行，作者一行，缺失作者显示“未知作者”。同一字体缩放下文字区等高；卡片与网格共享高度计算，预留字体取整和中文渲染余量。
- 窄屏网格的横向留白与间距更紧凑，避免漫画标题过窄；列数规则见 `specs/app-shell.spec.md`。封面元数据大字体下不突破卡片宽度。
- 首页续读浮条居中，最大宽度 520px；正文列表随系统字体缩放预留底部空间，最后一行可滚动到浮条上方。
- 个人列表使用独立面板和适当间距，最大内容宽度 960px；设置内容最大宽度 800px。设置主题选项互斥，窄屏或大字体下允许换行。
- 详情突出“开始阅读/继续阅读”，收藏作为次要按钮；当前章节有强调底色和“上次读到这里”的文字提示。
- 空态和错误态使用 `StatusView`/`EmptyListView`：淡强调圆形图标底、文案与可选重试按钮；空书库与无搜索结果有对应说明，空网格仍可下拉刷新。
- 阅读器保留既有沉浸外观及纯黑深色背景；工具栏、进度条与目录使用令牌。浅色阅读背景沿用 `readerBg`。进度条为细轨道，不改变隐藏与呼出行为。

## 交互反馈

- 侧栏悬停底色过渡 160ms；`Pressable` 按下缩放至 0.97，持续 120ms；Material 按钮动画 150ms。
- 网格卡片悬停放大至 1.02；侧栏页面切换采用 220ms 淡入与轻微上移；滚动条宽 8px。
- 按钮悬停、水波与高亮采用低透明度强调色。标题栏最小化/最大化悬停变亮，关闭按钮采用红底白图标。
- 路由推入使用 `FadeForwardsPageTransitionsBuilder`；导航动画不改变页面与阅读状态语义。
- 发现页“换一批”为右下角悬浮按钮，保留现有拖拽与点击阅读交互。

## 边界

- 不重绘封面或引入在线字体、插画依赖。
- 既有发现页及阅读器局部布局本轮沿用原有实现；新增界面仍需遵守主题令牌与可读性要求。
