# UI 样式约定

## 职责

规定 App 浅色与深色界面的视觉层次、组件样式和交互反馈。现有代码中残留的硬编码色值属于历史偏差，新代码使用主题令牌。

## 设计令牌

- 颜色由 `AppColors` 的浅/深两套 `ThemeExtension` 提供，组件通过 `context.appColors.*` 取色。
- 深色沿用后台蓝灰工作台：背景 `#111318`、面板 `#191c23`、导航 `#14171d`、次级表面 `#222630`、边框与分隔线 `#303540`；强调 `#91b2ee`、主文字 `#e8ebf2`、次要文字 `#9aa3b3`，强调按钮文字为深蓝 `#14213b`。
- 浅色为对应冷白蓝工作台：背景 `#f3f5f9`、面板与导航白色、次级表面 `#e9eef5`、边框与分隔线 `#d8e0eb`；强调 `#365f9c`、主文字 `#202936`、次要文字 `#59677a`。阅读画布预设独立于界面颜色。
- 页面背景、导航和内容面板保持可辨认的层次，主要阅读操作使用强调色。
- 字号：主要正文、导航、按钮与漫画标题16，辅助说明和作者14，页标题28、分组标题18，正文行高1.5；封面紧凑元数据12。开发水印与系统窗口标题保留紧凑尺寸，系统文字缩放仍受尊重。
- 圆角：卡片 12、缩略图 8、按钮 8、浮层 14、小角 6；集中在 `app/lib/theme.dart` 的 `kRadius*` 常量。
- 中文字体不打包：主题文字与按钮、选项使用统一简体中文字体栈（微软雅黑 → 苹方 → Noto Sans CJK SC → Source Han Sans SC）。

## 页面与组件

- 应用图标使用用户提供的粉色背景少女头像，保留原图人物构图、白色衣服与粉色背景。Windows、托盘、Android 普通启动器、iOS 和 Web 普通图标由同一原图生成；Windows 与托盘共用多尺寸 ICO。Android 自适应与 Web maskable 图标使用粉色背景并预留系统裁切空间；iOS 图标为不透明资源。
- 开发构建使用安全区左上角的小斜角 `DEVELOP` 水印，采用强调色背景与主题 `onPrimary` 文字色；浅色为蓝底白字，深色为浅蓝底深字。水印保持紧凑，窗口标题文字与其错开。构建范围与交互规则见 `specs/app-shell.spec.md`。
- Material 组件由 `buildAppTheme()` 统一提供样式；页面使用统一的标题、说明、间距与面板。面板与次要按钮使用中性表面和低对比细边界区分，避免重复描边；常规输入框保留边界及蓝色强调焦点反馈。
- 桌面导航宽216，提供蓝色品牌图标区和“浏览/我的书库”分组，选中项以淡强调底色和强调图标标识，未选项弱化，长标签允许换行。手机使用 Material 3 `NavigationBar`，保留“首页/我的”两个目的地。
- 首页与桌面书库使用统一页头，明确显示标题、说明和操作；窄屏或大字体时操作下移，避免挤压标题。首页明确显示“随便看看”“最近入库”或“搜索结果”、数量与对应刷新操作；桌面常驻搜索框提供提交和清空入口。
- 漫画封面保持 3:4，仅封面使用缩略图圆角，标题与作者位于透明文字区，不为整张卡片添加面板或外框。无封面时用书本图标占位；收藏角标位于右上角，话数/页数角标位于右下角，深色遮罩上的文字使用白色以保持对比度。
- 网格漫画标题与作者均为单行，超长内容省略；标题提供完整书名提示。缺失作者显示“未知作者”。同一字体缩放下文字区等高；卡片与网格共享高度计算，标题与作者采用与预算一致的固定行高，避免中文回退字体扩大行框，同时保留系统文字缩放。
- 窄屏网格的横向留白与间距更紧凑，避免漫画标题过窄；列数规则见 `specs/app-shell.spec.md`。封面元数据大字体下不突破卡片宽度。
- 首页续读浮条居中，最大宽度 520px，显示 5 秒后自动收起；可见期间正文列表随系统字体缩放预留底部空间，最后一行可滚动到浮条上方，收起后释放留白。
- 个人书库最大内容宽度 960px：最近阅读以封面与文字卡片展示，真实章节和页码使用淡强调底色；收藏以封面网格展示，单行书名与收藏角标沿用首页卡片；收藏作者以独立卡片展示头像占位、作者名、作品数、真实封面样本及“查看全部作品”。宽屏作者卡片两列，窄屏或大字体一列，卡片按内容自然增高。手机“我的书库”页签可横向滚动。设置内容最大宽度 800px，按“外观与窗口 / 阅读器 / 漫画服务器 / 关于”分组；宽屏说明与控件横向排列，窄屏或大字体改为纵向排列，互斥选项允许换行。
- 详情内容最大宽度 1120px 居中，上方为统一中性表面的封面与信息，宽屏并排、窄屏紧凑排列；下方章节目录按实际内容自然增高。取消整栏强调色渐变和撑满窗口的空目录面板。
- 详情操作顺序为收藏、打开本地目录（后端电脑）、阅读进度提示、开始／继续阅读；阅读按钮始终是操作区最后一个控件，保持唯一强调主操作，次要操作使用中性表面。
- 详情话数与页数使用中性色可换行标签；保留标题／作者复制、作者搜索和收藏。章节行使用中性表面，当前章通过小范围强调标识与“上次读到这里”区分，避免大面积强调色底板。
- 全屏搜索结果显示已提交关键字及匹配总数。首页排序菜单与刷新按钮可换行；大字体下排序入口使用带提示的图标，当前排序由页头及菜单说明。
- 搜索历史、目录、阅读设置和提示使用统一主题与圆角。阅读器菜单和面板内部提供关闭按钮，设置与目录在桌面右侧、手机底部；设置所有分组展开，内容滚动、标题与关闭固定；常用导航使用可换行的中性按钮组，淡蓝色用于选中状态；阅读选项不逐项套卡片，桌面标签与选项对齐，窄屏或大字体纵向排列，简短说明以提示保留。进度、阅读配置、超分、自动阅读和图片信息通过留白与细分隔线组织，超分状态及操作与策略位于同一组。面板外侧遮罩和内部 × 均可关闭。桌面右键与手机控制层菜单按钮直接打开统一阅读设置面板，顶部按章节与页码、进度条、上一章／目录／下一章排列三行；全屏与返回位于固定标题栏，与关闭按钮并列，下接全部设置；手机控制层不重复展示进度。
- 空态和错误态使用 `StatusView`/`EmptyListView`：淡强调圆形图标底、文案与可选重试按钮；空书库与无搜索结果有对应说明，空网格仍可下拉刷新。空态和错误态在受限高度内可滚动，重试操作保持可达。
- 阅读器正文默认沉浸，桌面通过右键、手机通过双击唤出操作；控制层手动关闭且覆盖正文，显隐不改变布局。画布保留跟随主题、深色、灰色、护眼米色预设；连续阅读通过设置面板集中提供缩放百分比、滑杆、加减与恢复默认按钮，并提示双指捏合或 Ctrl+滚轮；正文不常驻缩放工具。详细交互见 `specs/reader.spec.md`。

## 交互反馈

- 收藏页漫画角标与作者收藏按钮提供明确的取消提示，提交期间显示等待并防重复；首页和搜索角标仍为纯展示。操作失败保留内容，成功取消最后一项显示空态并反馈。
- 页面转场保持页面身份，不清空输入与滚动位置；减少动画偏好下直接呈现。后台刷新已有空列表时仍显示空态，不重新展示首次加载骨架。

- 首页、搜索和收藏网格首次等待显示封面与文字骨架，分页等待在已加载内容后追加一行占位；最近阅读、收藏作者和详情使用贴近各自内容形状的占位。详情后台刷新或刷新失败继续显示已有内容，无缓存失败保留错误与重试入口。
- 加载占位立即呈现，等待 150 毫秒后才启用轻量呼吸动效，不设置强制最短加载时间。封面和阅读图片首帧解码后以 180 毫秒淡入，命中同步缓存直接呈现；内容就绪不等待加载动画结束。
- 减少动画偏好下使用静态占位与直接呈现；停用 TickerMode 的区域不持续运行动效。占位沿用深浅主题，有限窗口可滚动，通常不因图片完成而改变占位高度；连续阅读原图的比例校正遵循阅读器锚点恢复规则。

- 侧栏悬停底色过渡 160ms；`Pressable` 按下缩放至 0.97，持续 120ms；Material 按钮动画 150ms。
- 网格卡片悬停放大至 1.02；侧栏页面切换采用 220ms 淡入与轻微上移；滚动条宽 8px。
- 按钮悬停、水波与高亮采用低透明度强调色。标题栏最小化/最大化悬停变亮，关闭按钮采用红底白图标；常规窗口按钮悬停使用主题次级表面色，标题栏与页面背景衔接。
- 路由推入使用 `FadeForwardsPageTransitionsBuilder`；导航动画不改变页面与阅读状态语义。

## 边界

- 不重绘封面或引入在线字体、插画依赖。
- 视觉调整保持搜索、随机序列、阅读位置、设置持久化与窗口行为契约；新增界面遵守主题令牌与可读性要求。
