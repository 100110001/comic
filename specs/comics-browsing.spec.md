# 漫画浏览与搜索

## 职责

提供漫画列表的浏览与搜索能力：列表接口支持分页、关键字过滤、随机与最近入库排序，并返回每本的收藏状态；首页网格统一浏览全库并提供连续阅读入口；搜索在桌面端内联、手机端全屏。

## 公开契约

- 列表、搜索、随机、作者作品和分页总数只包含未软删除漫画；标题或作者匹配均不能绕过此限制。旧漫画详情、章节图片、打开目录与阅读/收藏操作入口对已软删除漫画返回 404。已发布静态图片 URL 不因该标记增加数据库访问校验。

- `GET /api/comics`：分页列表，支持 `keyword`（标题/作者模糊匹配）与 `random=1`（随机排序）参数，二者可同时使用；每条返回 `favorited: boolean`。
- `sort=recent` 按首次入库时间降序，同一时间按漫画 ID 降序；可与关键字组合。`random=1` 优先于 `sort`；未指定或未知 `sort` 保持标题排序。
- `random=1` 时支持 `seed` 参数：同一种子下随机顺序稳定，配合 offset 分页不重复不漏；无 seed 时随机顺序不保证稳定。
- `random=1` 时 pageSize 上限为 500，其余请求上限为 100。
- 首页提供“随机推荐 / 最近入库”排序菜单，默认随机，选择在当前应用会话保留；排序切换回到列表顶部并重新加载首屏。随机模式刷新换种子，最近模式刷新重新获取最新入库列表。
- 首页网格每页条数为当前列数 × 6、最多 100，滚动加载更多。首页卡片进入详情后支持按该列表顺序连续阅读，见 `specs/reading-sequence.spec.md`。

- 搜索历史按规范化服务器地址分别保存最近 20 条，重启后恢复；仅去除关键字首尾空白，大小写和内部空白保持原样，完全相同的关键字移到最前。
- 显式提交、作者入口与点击历史均记录非空关键字，即使查询失败也保留；刷新、分页和失败重试不添加或重排历史。
- 全屏搜索结果展示当前已提交关键字与接口总数，输入中的未提交文本不改变查询结果标题。
- 手机空搜索页展示历史；手机和桌面搜索栏均提供历史面板，支持点击回填并立即查询、单条删除和清空当前服务器的历史。长关键字保留完整内容，列表支持滚动。

## 详情快捷操作

- 标题和非空作者名旁提供复制入口，复制完整原文并反馈成功或失败；作者名仍可进入作者搜索，旁边保留作者收藏。
- 详情提供“打开本地目录（后端电脑）”，通过 `POST /api/comics/:id/open-directory` 在运行后端的电脑上打开该漫画原文件夹，不打开当前客户端的文件夹。
- 接口只接收漫画 ID，成功响应为 `{ comicId }`；漫画不存在返回 404，无效 ID 拒绝。目录不可用、越界、缺失或系统打开失败提供中文失败反馈。
- 原文件夹由封面路径相对于配置的漫画根目录的第一级目录确定，章节图片与漫画目录直接放图均打开漫画目录；目标必须是存在的目录，规范化路径和真实路径都在漫画根目录内，根目录本身与符号链接越界被拒绝。
- 打开请求期间禁止重复点击；切换服务器或离开详情后，不显示旧请求反馈。系统打开请求成功不保证窗口已置于前台，后端需有可用的桌面环境及文件管理器。

## 不变量

- 列表、搜索和固定种子随机查询可缓存60秒；无种子随机保持每次查询。漫画收藏变更成功后相关列表缓存失效，具体规则见 `specs/backend-observability.spec.md`。

- 随机排序只改变顺序，不改变列表内容与总数。
- 同一种子下分页不出现重复或遗漏的漫画。
- `total` 为符合过滤条件的漫画总数。
- 首页输入关键字时切换到关键字分页列表；搜索结果保持标题排序，清空关键字恢复所选首页排序。
- 搜索仅展示最新提交关键字的结果；清空关键字后，旧搜索的晚到结果不得恢复旧查询。
- 首页内联搜索与各个全屏搜索页相互独立；从详情进入作者搜索再返回时保留外层搜索结果。提交新关键字回到列表顶部，同关键字刷新遵循原缓存规则。
- 首页切换排序、换种子或重新搜索后，旧查询的首屏、分页结果及错误不得覆盖新查询；同一查询加载更多期间，重复触底不重复发起请求。
- 首页首次加载期间的换批操作等待当前首屏，换批进行中重复触发共享同一次刷新，不重复生成种子或并行请求。完成或失败后可重新换批；分页中主动换批仍淘汰旧分页。
- 分页失败保留已加载内容并提供重试；搜索失败保留当前关键字，重试查询同一关键字。

- 切换服务器清空当前输入与查询标题，并显示新服务器的历史；其他服务器的历史保留，旧来源条目不得发起新服务器的查询。
- 新来源等待或请求失败时，不展示旧来源的书库、详情、收藏或最近阅读；当前来源已有本机待同步断点仍可用于续读。
- 历史保存独立于服务端查询，不因本地初始化或写入等待而延迟搜索；历史读取失败支持重试，保存失败提供反馈且保持上次成功保存的列表。

## 说明

- 页大小随实际网格内容宽度对应的列数动态计算（列数 × 6），窗口宽度变化后下一次请求生效；尺寸变化不重排或清空已加载内容，同一种子下后续分页仍无重复或遗漏。
- `pageOffset` 为从 1 起始的页号，接口偏移为 `(pageOffset - 1) × pageSize`；客户端改变页大小后按已消费位置续接，返回中已消费的重叠条目不重复展示，因此该次新增数量可能小于页大小。
- 最近排序在书库内容不变时具有确定顺序；offset 分页不提供入库并发期间的数据库快照，刷新重新取得最新列表。
